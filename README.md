# Oracle

TL;DR: I built a neural n-gram model to learn from sequences of football events with the goal of next-event prediction. 
The model significantly outperforms the baseline for almost all event fields in teacher-forced and autoregressive prediction tasks, 
but struggles with longer-horizon event prediction.

I write in more detail about the project here: https://apophenia57.com/posts/neural-n-gram-models-for-match-simulation
